# ReconifyX 1.0.0

本地自部署的攻击面管理（ASM）工具的首个公开版本：一个域名进去，一份报告出来。
*The first public release of a local, self-hosted attack surface management tool:
one domain in, one report out.*

---

## 中文

### 这个版本能做什么

- **三条逐层加深的管线**：`Basic`（被动子域名 + DNS 情报）→ `Pro`（+ HTTP 探活、
  TLS 证书、安全响应头、SPF/DMARC 审计）→ `Ultra`（+ 子域名接管检测）。
- **风险总账**：0-100 加权分 + A-F 等级 + 按严重度排序的聚合风险项。
- **历史差异**：与同域名上一次扫描做 diff，首次扫描显式返回 `baseline=true`。
- **三种交付形态**：命令行 `reconifyx`（scan / dns / serve / version）、WebUI、
  HTTP API（含 Prometheus 指标）。
- **诚实降级**：上游挂了或结果被截断时写进 `degraded` / `probe_complete` /
  `audit_complete` / `takeover_complete` 等对外字段，CLI 以非零退出码告知 CI。
- **零密钥可用**：默认不注册任何 API key 也能跑；CertSpotter / FOFA 是可选的增强源。

### 安装

```bash
# 源码
git clone https://github.com/Cat-liko/ReconifyX-V2.git && cd ReconifyX-V2
python -m pip install -r requirements.txt
python -m reconifyx serve

# 或直接用 Release 里的 Windows 单文件 exe（无需 Python）
```

### 已知限制

FOFA 依赖非官方中转站；接管检测有 Azure NXDOMAIN 盲区；缓存与 job 存储在进程内
（单 worker）；不做端口扫描与漏洞利用。详见 README「已知限制」。

## English

### What this release does

- **Three progressively deeper pipelines**: `Basic` (passive subdomains + DNS intel) →
  `Pro` (adds HTTP liveness, TLS certificates, security headers, SPF/DMARC audit) →
  `Ultra` (adds subdomain-takeover detection).
- **Risk ledger**: a 0–100 weighted score with an A–F grade and findings aggregated by
  severity.
- **History diff**: compare against the previous scan of the same domain; the first scan
  returns `baseline=true` explicitly.
- **Three delivery forms**: the `reconifyx` CLI (scan / dns / serve / version), a WebUI,
  and an HTTP API with Prometheus metrics.
- **Honest degradation**: when an upstream fails or results are truncated it is reported
  through public fields (`degraded`, `probe_complete`, `audit_complete`,
  `takeover_complete`), and the CLI exits non-zero so CI can tell.
- **No API keys needed**: works out of the box; CertSpotter and FOFA are optional
  enhancement sources.

### Install

```bash
# From source
git clone https://github.com/Cat-liko/ReconifyX-V2.git && cd ReconifyX-V2
python -m pip install -r requirements.txt
python -m reconifyx serve

# Or grab the single-file Windows exe from this release (no Python required)
```

### Known limitations

FOFA depends on an unofficial relay; takeover detection has an Azure NXDOMAIN blind spot;
the cache and job store are in-process (single worker); no port scanning and no exploit
delivery. See "Known limitations" in the README.
