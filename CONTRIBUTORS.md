## 关于 GitHub 侧边的 Contributors 列表

仓库首页右侧那块头像列表由 GitHub 自动计算,规则是:**以自己 GitHub 账号身份**
提交过至少一次的人才会出现。因此:

- 只出现在本文件或 README 致谢里的名字,只要没有以本人账号提交过,就不会出现在那里;
- 没有 GitHub 账号的协作方(例如 AI 工具)不会出现,但它们会出现在
  **每个提交页面的 `Co-authored-by`** 里,这是 GitHub 对非账号协作方能给的最高可见度。

*The avatar list on the repository sidebar is computed by GitHub: only people who have
authored at least one commit with their own GitHub account appear there. Names credited
only in this file or the README will not show up unless that account has committed.
Collaborators without a GitHub account (AI tools, for example) never appear there, but they
do appear in `Co-authored-by` on the commit pages — the strongest visibility GitHub offers
to non-account collaborators.*

## 如何添加自己 / How to add yourself

1. 在 GitHub 网页上打开本文件,点右上角铅笔图标;
2. 在你的名字那一行补一句你做了什么(一行即可);
3. 页面底部 **Commit changes** —— 这次提交的作者就是你的账号,几分钟后你就会出现在
   仓库右侧的 Contributors 列表里。

*Open this file on GitHub, click the pencil icon, add one line describing what you did,
then "Commit changes" at the bottom. That commit is authored by your account, and you will
appear in the repository's Contributors list within a few minutes.*
